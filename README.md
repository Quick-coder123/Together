# Хамелеончики — затишний куточок для двох 🦎❤️

Застосунок для пари (PWA): встановлюється на головний екран телефона, усе українською.

- **Ми** — пара й лічильник днів разом, побачення й поїздки, перші кроки, хамелеон, що змінює колір під ваш настрій (годування, вогник днів поспіль, 7 міні-ігор що чергуються, колекція знахідок з рідкісними предметами, завдання дня, рівні, гардероб), настрій, «Що попереду», записка-сюрприз, «Вечір: кіно + рецепт», чек-ін, скарбнички, важливі дати.
- **Місця** — спонтанні й заплановані місця, пошук і фільтр, випадкове місце, **«Куди піти?»** (ШІ підбирає справжні місця з OpenStreetMap біля тебе або в обраному місті й пропонує ідею побачення), побачення наосліп (деталі приховані від партнера до дня побачення).
- **Дім** — покупки (продукти / інші, швидкі теги), справи з повтором і відповідальним, рецепти з додаванням інгредієнтів у покупки, **Випадковий рецепт** з фото: справжній рецепт з відкритої бази TheMealDB, перекладений українською безкоштовним ШІ Gemini.
- **Вішліст** — подарунки («Хочу я» / «Хоче партнер», підготовку подарунка бачить лише дарувальник), «Подивитися», мрії.
- **Ще** — подорожі (напрямки з місцями, зборами й витратами, швидкі відмітки), календар (місяць / тиждень, фільтр), цілі-скарбнички з історією, щотижневий чек-ін (відповіді відкриваються, коли відповіли обоє), записки (зокрема запечатані до певного часу), налаштування (фото, тема), часті питання.

## Акаунти

Кожен з пари має свій логін і пароль (зберігається лише scrypt-хеш). Увійти можна з будь-якого пристрою — дані тягнуться з сервера. Код пари потрібен лише, щоб друга половинка приєдналася.

## Розгортання на Vercel

1. Vercel → **Add New → Project** → імпортувати репозиторій `Together` (Framework Preset: **Other**, решту не змінювати) → Deploy.
2. У проєкті: **Storage → Create Database → Upstash for Redis** (безкоштовний план) → **Connect** до проєкту.
   Vercel сам додасть змінні `KV_REST_API_URL` і `KV_REST_API_TOKEN`.
3. **Deployments → ⋯ → Redeploy**, щоб сервер побачив базу.
4. (Безкоштовно, для перекладу рецептів українською) На https://aistudio.google.com/apikey створи ключ (без картки) →
   у Vercel **Settings → Environment Variables** додай `GEMINI_API_KEY` → Redeploy. Без ключа рецепти показуються англійською.
   Необовʼязково: `GEMINI_MODEL` (типово `gemini-3.5-flash-lite`), `AI_DAILY_LIMIT` (типово 30 пошуків на пару на день).
   Платна альтернатива з живим веб-пошуком: `ANTHROPIC_API_KEY` (використовується, лише якщо немає `GEMINI_API_KEY`).
5. Відкрити адресу на телефоні → «На екран “Додому”» (iPhone, Safari) або «Встановити застосунок» (Android, Chrome).

## Локально

```
npm run dev   # http://localhost:3000, дані зберігаються в памʼяті
```

## Будова

- `index.html`, `styles.css`, `js/` — інтерфейс (без фреймворків і збирання).
- `lib/core.js` — модель даних і всі дії (спільна для сервера й клієнта).
- `js/games.js` — міні-ігри з хамелеоном.
- `api/places.js` — «Куди піти?»: Nominatim + Overpass (OpenStreetMap) + Gemini.
- `api/recipe.js` — пошук рецептів: TheMealDB + переклад Gemini (або Claude з веб-пошуком).
- `api/auth.js` — акаунти: логін/пароль, вхід з будь-якого пристрою.
- `api/state.js` — функція Vercel: зберігання в Upstash Redis, приватність даних для кожного з пари.
